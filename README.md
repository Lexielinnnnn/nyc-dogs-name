# What's in a (Dog) Name? — NYC Dog Licensing Data Story

A data-storytelling project that explores how New Yorkers name their dogs, using
the public NYC Dog Licensing Dataset. We ask four questions:

| # | Question | Script |
|---|----------|--------|
| Q1 | What are the most common dog names in NYC, and how do they compare with the national Top 100? | `top_names.py` |
| Q2 | Do dog names differ by age (birth year)? Which names are "classic" and which are "emerging"? | `name_trends.py` |
| Q3 | Do popular names differ across the 10 most common breeds? | `breed_naming.py` |
| Q4 | Do popular names differ across the five boroughs? | `zip_naming.py` |

---

## Dataset

**NYC Dog Licensing Dataset** — published by the NYC Department of Health and
Mental Hygiene (DOHMH) on NYC Open Data (Socrata dataset ID `nu7n-tubp`).

- Landing page: https://data.cityofnewyork.us/Health/NYC-Dog-Licensing-Dataset/nu7n-tubp
- API endpoint used by `fetch_data.py`: `https://data.cityofnewyork.us/resource/nu7n-tubp.json`
- **Unit of observation:** one row = one *license period*, not one dog. There is
  no persistent dog ID, so the same dog can appear several times across years
  (see "Limitations").
- **Fields we use:** `animalname`, `animalgender`, `animalbirth`, `breedname`,
  `zipcode`, `licenseissueddate`, `licenseexpireddate`, `extract_year`.

**Citation**

> NYC Department of Health and Mental Hygiene. *NYC Dog Licensing Dataset*
> (`nu7n-tubp`). NYC Open Data. https://data.cityofnewyork.us/Health/NYC-Dog-Licensing-Dataset/nu7n-tubp.
> Accessed 2026.

**Reference data**

- `data/reference/nyc_zip_to_borough.csv` — ZIP → borough crosswalk built from
  NYC DOHMH ZCTA/MODZCTA files. Sources, method and caveats are documented in
  [`data/reference/borough_mapping_notes.md`](data/reference/borough_mapping_notes.md).
- National Top 100 dog names (Rover.com 2025 report, as reported by Newsweek),
  hard-coded in `top_names.py` for the Q1 comparison.

## How to reproduce

**Requirements:** Python 3.10 or newer.

1. **Clone the repository**

   ```bash
   git clone https://github.com/Lexielinnnnn/nyc-dogs-name.git
   cd nyc-dogs-name
   ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **(Optional) Set an NYC Open Data app token** to avoid API throttling.
   Get a free token at https://data.cityofnewyork.us/profile/edit/developer_settings

   ```bash
   export NYC_OPEN_DATA_APP_TOKEN=your_token_here
   ```

4. **Download the raw data** → `data/raw/nyc_dog_licenses_raw.csv`

   ```bash
   python fetch_data.py
   ```

   The script pages through the API (50,000 rows per request), checks for
   duplicate row IDs, and verifies the final row count matches the API total.

5. **Clean the data and build features** → `data/clean/nyc_dog_licenses_clean.csv`

   ```bash
   python clean_data.py
   ```

6. **Run the analyses** (any order; each reads the clean CSV)

   ```bash
   python top_names.py      # Q1 -> output/q1_*.csv, figures/q1_top20_bar.png
   python name_trends.py    # Q2 -> output/q2_*.csv/.txt, figures/q2_trend_lines.png
   python breed_naming.py   # Q3 -> results/q3_breed_naming.csv, figures/q3_breed_naming.png
   python zip_naming.py     # Q4 -> results/q4_borough_naming.csv, figures/q4_borough_naming.png
   ```

## Preprocessing and feature engineering

Feature engineering lives inside `clean_data.py` (record-level features) and at
the start of each analysis script (analysis-specific features). They are
summarized here so they are easy to find.

### Record-level features — `clean_data.py`

| Feature | Function | How it is built |
|---------|----------|-----------------|
| `animal_name` (cleaned) | `clean_names()` | Trim/collapse whitespace, remove placeholders ("NAME NOT PROVIDED", "UNKNOWN", digits-only…), title-case |
| `birth_year` | `extract_birth_year()` | Parsed from the raw birth field (year or year-month); kept only if between 1990 and the current year |
| `breed_name` (cleaned) | `clean_breed()` | Normalize whitespace/casing, remove placeholder values |
| `zip_code` (cleaned) | `clean_zip()` | Strip `.0` and ZIP+4 suffixes, keep valid 5-digit ZIPs, drop `00000`/`99999` |
| `borough`, `modzcta` | `add_borough()` | Many-to-one join with the ZIP → borough crosswalk; cross-borough ZIPs (10463, 11370) left blank |
| `borough_mapping_status` | `add_borough()` | Categorical: mapped / ambiguous / unmatched ZIP / missing or invalid ZIP |
| `possible_repeat_license` | `flag_duplicate_licenses()` | Boolean flag for rows sharing (name, gender, breed, ZIP, birth year) — approximates the same dog renewing |
| `license_issued_date`, `license_expired_date` | `clean()` | Converted to datetime |

### Analysis-level features

| Feature | Script / function | Purpose |
|---------|-------------------|---------|
| `birth_bucket` (5-year bins) | `name_trends.py` → `add_birth_bucket()` | Groups dogs by birth period for Q2 and the chi-square test |
| Name × bucket contingency table | `name_trends.py` → `run_chi_square()` | Input to the chi-square test (names with ≥ 20 records) |
| `status` = classic / emerging | `name_trends.py` → `classify_emerging_vs_classic()` | Labels names that stay in every bucket's Top 20 vs. names new to the latest Top 20 |
| `rank`, `national_rank`, `in_national_top_100` | `top_names.py` → `compute_top_names()`, `compare_to_national()` | NYC rank and match against the national Top 100 |
| Top-10 breed groups | `breed_naming.py` → `main()` | Restricts Q3 to the 10 most common breeds |

## Key results (from the committed outputs)

- **Q1:** The most common NYC dog names are Bella, Luna, Max and Charlie
  (`output/q1_top_names.csv`); NYC's top names largely overlap with the
  national Top 100 (`output/q1_national_comparison.csv`).
- **Q2:** Name distribution differs significantly across birth-year buckets
  (chi-square, p < 0.05; `output/q2_chi_square_result.txt`). Names such as
  Luna, Milo and Teddy are "emerging" (`output/q2_emerging_vs_classic_names.csv`).
- **Q3 / Q4:** Top-5 names by breed and by borough are in `results/` and
  visualized in `figures/q3_breed_naming.png` and `figures/q4_borough_naming.png`.

---

## Limitations

- Rows are license records, not unique dogs; renewals can be counted more than
  once. `possible_repeat_license` flags likely repeats but is an approximation.
- Licensed dogs are not all dogs in NYC — licensing rates may differ by
  borough and owner group.
- The ZIP → borough mapping is approximate (statistical geography, not USPS);
  records with ambiguous or unmatched ZIPs are kept but have no borough.
- Very old birth years (1990s) have small samples; read early buckets with care.
